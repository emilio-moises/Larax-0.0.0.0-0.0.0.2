# Licencias recomendadas para Larax

Este documento describe algunas licencias comunes y recomendadas para proyectos de software libre, como Larax, un lenguaje de programación en desarrollo.

---

## 1. MIT License

**Descripción:**  
Una licencia muy permisiva que permite reutilización libre con pocas restricciones, incluso para proyectos comerciales. Solo requiere incluir el aviso de copyright y la licencia en las distribuciones.

**Ideal para:**  
Proyectos que buscan máxima libertad para usuarios y desarrolladores, facilitando contribuciones y uso comercial.

**Texto de licencia:**  
[MIT License (ejemplo más abajo)](#mit-license-text)

---

## 2. Apache License 2.0

**Descripción:**  
Permisiva como MIT, pero con cláusulas explícitas sobre patentes, lo que puede proteger mejor tanto a los contribuidores como a los usuarios.

**Ideal para:**  
Proyectos donde la protección contra reclamaciones de patentes es importante.

**Texto de licencia:**  
[Apache License 2.0 (enlace oficial)](https://www.apache.org/licenses/LICENSE-2.0)

---

## 3. GNU General Public License v3.0 (GPLv3)

**Descripción:**  
Licencia copyleft fuerte. Obliga a que cualquier software derivado sea también libre bajo GPL. Garantiza que el software y sus derivados permanezcan libres.

**Ideal para:**  
Proyectos que quieren asegurar que el código y derivados siempre serán libres.

**Texto de licencia:**  
[GPLv3 License (enlace oficial)](https://www.gnu.org/licenses/gpl-3.0.en.html)
